# Jee misses IEM Beijing — fan-made HLTV-style page

A single-page fictional CS2 news mockup. The article and the comment are invented; this is an unofficial fan-made page and is not affiliated with HLTV.org. It uses local static assets and links back to real HLTV pages.

## GitHub Pages

The `main` branch deploys automatically through `.github/workflows/pages.yml`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The published URL will be `https://<account>.github.io/<repository>/`.
